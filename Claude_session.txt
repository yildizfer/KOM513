## **Why Gymnasium?**

Gymnasium (formerly OpenAI Gym) is **not specific to Keras** — it's a standardized interface for RL environments. Any RL algorithm (Keras, PyTorch, stable-baselines3, etc.) expects an environment with:
- `.reset()` → initial observation
- `.step(action)` → (observation, reward, done, info)
- `.observation_space` and `.action_space`

You *could* skip it and write a direct loop: `for step in range(n): action = ddpg_model.predict(obs); new_obs = forward_kinematics(action); ...` But gymnasium provides:
- **Standardization** — any RL algorithm fits this interface
- **Reward abstraction** — encapsulates domain logic
- **Episode management** — handles reset, termination, clipping
- **Portability** — swap algorithms without rewriting your simulation

---

## **What is AmorphousSpace?**

It's a custom observation space that defines the **reachable workspace** of your robot as irregular circular regions.

Looking at `circles.txt`:
```
-0.07,0.07,0.23   ← Circle 1: center (-0.07, 0.07), radius 0.23 m
-0.01,0.13,0.23   ← Circle 2: center (-0.01, 0.13), radius 0.23 m
```

**Why "amorphous"?** Instead of a simple rectangular box (like `Box(-1, 1, shape=(2,))`), it has an irregular/formless shape made of overlapping circles. 

**What does it do?**
- `contains(point)`: Checks if tip position is within valid workspace
- `clip(point)`: If the robot tries to reach outside workspace, snap it back to nearest boundary
- `sample()`: Generate random valid starting/goal positions
